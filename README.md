# 讀書柴犬｜AI 學習筆記站

這是我整理 AI 課堂概念的筆記網站，目前有 Prompt、RAG、Reflection 和 AI Agent 四篇入門筆記。希望透過簡單的說明、生活例子和小練習，讓自己方便複習，也讓剛接觸 AI 的人比較容易理解。

網站以米白色、棕色和橘色為主，搭配柴犬表情符號，延續「讀書柴犬」陪伴讀書的感覺。

## 網站連結

- 網站：https://uuyu1377.github.io/study-shiba-notes/
- GitHub：https://github.com/uuyu1377/study-shiba-notes

## 網站內容

目前收錄四篇筆記：

- **Prompt 入門**：如何把任務、背景和輸出要求說清楚。
- **RAG 入門**：先找相關資料，再根據資料回答問題。
- **Reflection 入門**：透過初稿、檢查和修正改善內容。
- **AI Agent 入門**：理解 AI 如何使用工具，並根據結果決定下一步。

每篇筆記都有學習目標、核心概念、具體例子、常見誤解、小練習與重點回顧。練習的參考答案可以展開，方便先自己想過再看答案。

## 使用方式

可以直接透過上方網站連結閱讀。

如果下載 ZIP，請先完整解壓縮，再進入資料夾，用瀏覽器開啟 index.html。點選首頁卡片就能閱讀筆記，各篇筆記也都有返回首頁的連結。

網站使用 HTML 和 CSS 製作，不需要安裝套件或設定 API 金鑰。解壓縮後可以離線閱讀，外部參考資料則需要網路才能開啟。網站主要用來介紹概念，沒有串接聊天模型。

## 檔案結構

- `index.html`：首頁與筆記入口。
- `assets/css/style.css`：全站共用樣式。
- `notes/`：各篇筆記。
- `templates/note-template.html`：新增筆記時使用的範本。
- `AGENTS.md`：AI 開發與修改專案時要遵守的規則。
- `README.md`：專案介紹與使用說明。

## AGENTS.md 的用途

這次作業除了完成網站，我也把後續開發方式整理進 AGENTS.md，包括網站風格、檔案命名、資料夾位置、筆記格式和修改後的檢查項目。

例如，每篇筆記都要包含相同的內容段落，放在 notes 資料夾，並使用共用 CSS。新增筆記後，也要同步更新首頁入口。

這樣之後請 AI 新增內容時，就不用每次重新說明整個網站的做法。

## 如何新增筆記

1. 請 AI 先閱讀 AGENTS.md 和現有筆記。
2. 提供要新增的主題及必要資料。
3. 從 templates/note-template.html 複製一份，放進 notes 資料夾。
4. 使用小寫英文與連字號命名，例如 learning-basics.html。
5. 修改標題、簡介、標籤和各段內容，保留原本的段落結構。
6. 沿用共用 CSS 和返回首頁的相對路徑。
7. 在首頁新增筆記卡片，並更新筆記篇數。
8. 檢查新筆記、首頁入口和答案展開功能。

如果修改共用 CSS，也要一起檢查其他頁面，避免影響原本的排版。

可以使用以下指令請 AI 新增筆記：

> 請先閱讀 AGENTS.md，依照現有範本新增一篇「○○入門」筆記，沿用共用樣式與段落格式，並更新首頁入口。完成後說明新增及修改了哪些檔案。

## 檢查方式

製作過程中，使用程式檢查了 HTML 結構、標題層級、必要段落，以及站內連結和 CSS 路徑。這些檢查可以確認檔案結構與連結目標，但不能代替實際操作。

更新網站後，還需要用瀏覽器確認：

- 首頁卡片能進入正確的筆記。
- 每篇筆記都能返回首頁。
- 參考答案能正常展開與收合。
- 手機與電腦上的文字及排版是否正常。
- 使用鍵盤 Tab 時，能看出目前選到的連結或控制項目。

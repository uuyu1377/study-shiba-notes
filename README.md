# 讀書柴犬｜AI 學習筆記站

給 AI 初學者的繁體中文筆記網站，包含 Prompt、RAG 與 Reflection 三篇入門筆記。採米白背景、深棕文字與橘色重點色，搭配簡單柴犬表情符號陪讀；表情符號的外觀依裝置而異。

## 開啟方式

1. 完整解壓縮 ZIP，不要直接在壓縮檔預覽中開啟。
2. 進入 study-shiba-notes 資料夾，用瀏覽器開啟 index.html。
3. 點選筆記卡片閱讀，點「查看參考答案」展開答案，再用返回首頁連結繼續閱讀。

網站只使用 HTML 與 CSS；答案展開使用 HTML 原生 details / summary。不需要安裝套件、編譯、後端、資料庫、API 金鑰或網路連線。外部延伸閱讀連結則需要網路。本專案介紹 AI 方法，沒有實際聊天或模型推論功能。

## 專案檔案

- index.html：首頁與三篇筆記卡片。
- assets/css/style.css：全站唯一的共用樣式。
- notes/prompt-basics.html：Prompt 入門。
- notes/rag-basics.html：RAG 入門。
- notes/reflection-basics.html：Reflection 入門。
- templates/note-template.html：含完整示範內容的筆記範本。
- README.md：操作與維護說明。
- AGENTS.md：保留使用者提供的 AI 開發規則。

## 上傳至 GitHub Pages

把 study-shiba-notes 資料夾「裡面的內容」上傳至準備發布的儲存庫根目錄，讓 index.html 直接位於根目錄，並保留 assets、notes、templates 的資料夾結構。不要只上傳 ZIP，也不要只上傳 index.html。

接著在儲存庫的 GitHub Pages 設定中，選擇對應的發布分支與根目錄來源。發布完成後，用 GitHub 提供的網站網址開啟首頁。這次交付並未替你建立儲存庫或實際部署；發布權限、方案與介面以你的帳號顯示為準。

所有站內路徑都是相對路徑，能用於 GitHub Pages 的專案子路徑。部署後請再確認三張卡片、共用樣式與返回首頁都正常。

## 如何新增筆記

1. 先閱讀 AGENTS.md 與現有筆記，確認主題與必要資料。
2. 複製 templates/note-template.html 至 notes/，使用小寫英文與連字號命名，例如 learning-basics.html。
3. 範本提供完整的 Prompt 示例，避免空白頁。請依新主題替換頁面 title、meta description、筆記序號、標籤、h1、簡介與各段內容；替換指引也寫在 HTML 註解中。
4. 保留學習目標、核心概念、具體例子、常見誤解、小練習與參考答案、重點回顧等六個 h2 段落。每頁只有一個 h1。
5. 更新參考來源，保留 ../assets/css/style.css 與 ../index.html 的相對路徑。不要把 CSS 複製到筆記中。
6. 複製首頁一個 article.card 區塊，修改序號、標題、標籤、簡介、連結文字與 href；連結必須對應已完成的新檔案。同時更新首頁的筆記篇數。
7. 開啟首頁點進新筆記，再返回首頁；確認答案可展開。檢查手機寬度、鍵盤 Tab 焦點與文字是否清楚。
8. 若改動共用 CSS，重查首頁、所有筆記及範本。

範本沒有放進首頁清單，不會讓讀者誤以為是第四篇正式筆記。

## 內容與來源

各篇筆記頁尾附參考與延伸閱讀。Prompt 與 RAG 參考 OpenAI 的提示工程指南；Reflection 的延伸閱讀為 Madaan 等人（2023）的 Self-Refine。文字為入門概念整理，作業與遊戲例子均為自訂教學示例，並非實際課程規定或測試成果。

網站未使用外部字型、圖片服務、追蹤工具或 JavaScript。柴犬使用系統表情符號，無須額外下載圖片。
